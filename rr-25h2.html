Keep your Revolt current.Two quick passes, the safe way.

Own a Revolt PC—or converted your own to RR Turbo? Two small tools keep it healthy and secure: a Tune-Up finishing pass, then the 24H2 → 25H2 security update. Run them in order—each is one double-click and a restart, and neither undoes your cleanup.

The two passes

Run the Tune-Up first, then the update.

Both tools live in the same open repo. Do them in order: the Tune-Up brings your machine fully current and clears a memory drain; the update then moves Windows to a version that still gets security patches.

① Run this first

RR Tune-Up

The finishing pass · RR Turbo v6 and newer

A one-pass field update for a Revolt machine that’s already set up. It brings a shipped unit fully current and clears the SearchHost WebView2 drain—roughly 360 MB of idle memory Windows quietly spawns for Bing search—then re-asserts the debloat so nothing crept back after an update.

Download RR Tune-Up →
  • Extract the download.
  • Double-click RUN - RR Tune-Up.bat (it self-elevates).
  • Restart when it’s done.
② Then this

RR Turbo Update — 24H2 → 25H2

The security update · Windows 11

Windows 11 24H2 stopped getting security updates in October 2026. This moves you to 25H2 so patching continues—using Microsoft’s own signed enablement package, not a reinstall. No Copilot back, no telemetry switched on, nothing you set lost.

Download the Update →
  • Extract, open the 24H2-to-25H2 folder (plug a laptop in first).
  • Double-click Run-Step1-Download.bat.
  • Double-click Run-Step2-Install.bat — Yes for admin, then restart.
  • Confirm: winver reads build 26200.
What this is

The update, without the backsliding.

A big Windows feature update (like 24H2→25H2) often quietly switches the bloat back on—Copilot, Recall, telemetry, the lot.  This one doesn’t: it uses Microsoft’s own signed update—an enablement package that flips on features already present, not a reinstall—so nothing you removed comes back and nothing you set is lost.

What it does
  • Moves Windows 11 from 24H2 to 25H2
  • Uses Microsoft’s own signed update — verified before it installs
  • Keeps your files, apps, and settings
  • Walks you through it, step by step
What it never does
  • Turn Copilot or Recall back on
  • Re-enable telemetry you had removed
  • Touch or upload your personal files
  • Lock you in — you can see every step
One thing you might see

A blue “Windows protected your PC” box

The first time you run it, Windows may show a blue box that says “Windows protected your PC.”  That’s SmartScreen being cautious with any small, unsigned tool—not a warning that something is wrong.  Click More info, then Run anyway.  Prefer to read it first?  It’s plain text you can open in Notepad before you run.
